Watch Out for Copy-Paste Linebreaks vs. Visual Soft-Wrap

  • Hard-inserting newline characters that break copied code: Unlike scripts that mutate code strings with hard \n breaks, CleanPrint uses CSS soft-wrapping (pre-wrap), so selecting text in the exported PDF still copies unbroken logical lines!
  • Printing with 200% browser zoom active: Reset zoom to 100% or use CleanPrint's dedicated font-size scale (10pt–12pt) for dense, crisp code.

Frequently Asked Questions

If CleanPrint wraps long code lines onto the next line for printing, does copying from the PDF add fake line breaks?

Because CleanPrint applies CSS white-space: pre-wrap rather than inserting literal newline characters into the DOM text, modern PDF viewers preserve clean logical text flow without losing any truncated characters!

Does CleanPrint also prevent Markdown tables and headings from orphaning at the bottom of a page?

Yes! CleanPrint injects break-after: avoid on h1–h4 headings (so a heading never sits alone at the bottom of a page) and break-inside: avoid on table rows and compact callouts.

Which browsers support CleanPrint Studio?

Microsoft Edge, Mozilla Firefox, Google Chrome, Brave, and Arc (standard Manifest V3 architecture).
